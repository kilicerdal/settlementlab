# Security scope

SettlementLab version one is an unauthenticated, loopback-only educational application. It is intended for synthetic data on a developer workstation. It does not provide participant authorization, production-grade HTTP serving, immutable audit storage, or public hosting controls.

Do not include credentials or real financial records in issues, traces, screenshots, or fixtures. When reporting a vulnerability, provide a minimal synthetic reproduction and affected version. If private reporting is enabled on the repository, use that channel for security-sensitive details.

Before exposing a future interactive deployment, implement authentication, participant authorization, request/resource limits, secure session handling, and deployment-specific monitoring. A static case study or screenshot gallery does not require publishing the local API.

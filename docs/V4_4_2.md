# V4.4.2 — investigator presentation and local evaluation

V4.4.2 packages the AI improvements merged after V4.4.1. The financial workbench wheel now includes canonical investigator presentation and the stronger local evaluation. The independent HTTP assurance engine remains domain-free and receives a matching version; it does not include the investigator or claim an AI feature change.

## What changed

The model can produce valid JSON claim citations alongside misleading prose. The investigator now renders its displayed summary from fixed descriptions and validated per-claim evidence IDs, with fixed uncertainty text. For example, `POSITION_LAG [position:event2]` and `COMPENSATION_POSTED [journal:inverse]` remain explicitly paired. Other validated references remain in their corresponding structured claim links. Unknown codes or invalid presentations fail closed.

The local evaluator preserves both raw responses and displayed analysis. All-requested success denominators expose unavailable, invalid and unattempted slots. Reports include supported-observation coverage, per-context omissions, citation-aware repetition consistency, failure categories, latency and atomic progress checkpoints. Existing evidence cannot be overwritten. See [measurement definitions and retained limitations](LOCAL_AI_EVALUATION.md).

This fixes what the investigator serves, not the underlying model's prose generation. Historical live samples are retained with their original source fingerprints; the release does not claim a new model run or general factual accuracy.

## Install and verify

Download the workbench wheel and checksums from [V4.4.2](https://github.com/kilicerdal/settlementlab/releases/tag/v4.4.2), verify its hash, then use a virtual environment:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install --no-index ./settlementlab-4.4.2-py3-none-any.whl
.venv/bin/python -c 'from importlib.metadata import version; print(version("settlementlab"))'
.venv/bin/settlementlab-incident --serve --output ./incident-v442
```

Use a fresh output directory and free port 8086; open http://127.0.0.1:8086/investigation. This generates a completed synthetic incident with AI disabled. To opt into inference, add `--model qwen2.5:3b` only when that local Ollama model is already installed. No key, paid service or source checkout is required.

For the domain-free engine, install `settlementlab_assurance-4.4.2-py3-none-any.whl`; see [standalone assurance](STANDALONE_ASSURANCE.md).

## Release validation

The exact workbench artifact is installed outside the checkout in clean Python 3.9 and 3.13 environments. In addition to metadata, cold-WAL read-only protection, HTTP startup and actual incident recovery, the wheel verifier injects the known attribution error through the installed investigator and checks the corrected served bindings. A separate injected unavailable-model call must remain in the evaluation denominator (5/6 overall versus 1.0 conditional acceptance). These injected checks make zero live model calls.

Source controls comprise 228 tests plus four assurance scenarios, coverage and lint/type gates, actual browser/HTTP regression, reuse, workload and installed-wheel checks. Published evidence records the exact build source, release tree and artifact hashes. The manifest is unsigned; it is not independent human attestation.

No schema migration, production financial connection, model download or website change. Earlier releases and their historical media remain unchanged.
